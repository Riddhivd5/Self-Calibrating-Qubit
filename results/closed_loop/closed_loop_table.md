# Closed-loop logical error rate: frozen, periodically recalibrated, oracle and adaptive decision boundaries

d = 5 rotated surface code, physical error 0.001, fixed PyMatching decoder built at the calibration-time readout error. LER in percent, pooled over runs, with the 95% interval from resampling (runs for simulated drift; window blocks for the real replay, which is one 15.6-day trajectory re-sampled, so its interval covers sampling noise only). Recovery = share of the frozen-to-oracle LER gap that an arm removes, with a 95% bootstrap interval over runs (for the real replay the runs are re-samplings of the same trajectory, so that interval is narrow and covers sampling noise only); it is not reported when the gap is not distinguishable from zero. 'Same window' scores a boundary on the window it was just tuned on (offline re-assignment); 'online' scores each window at the boundary from before that window's data. Source: ler_summary.md in controlled/, fitted/, real/.
